# ⚡ Science Spark

A single-file, voiced, visual science-learning web app for kids — **Grade 2 · Earth & Space** (more grades coming).

Built to teach reasoning-first, with animated visuals (spinning Earth for day/night, Earth orbiting the Sun, the tilted-axis seasons diagram, a cut-away Earth's-layers model, a continents map) plus a **Play** mode that tests each idea with big visual-choice questions and plain multiple choice.

**Topics:** Solar System · Day & Night (rotation) · Seasons (revolution + tilt) · Earth's Layers · Water & Land · Continents · Geologists.

- **Live:** https://tboy2020.github.io/science-spark/
- **App file:** `index.html` (self-contained — inline CSS/JS, no build)
- **Deploy / redeploy:** push to `main`; GitHub Pages serves it from the repo root.
